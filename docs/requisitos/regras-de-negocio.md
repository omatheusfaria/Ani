# Regras de Negócio

Este documento descreve as regras e restrições de comportamento atualmente alinhadas à reformulação filosófica de **Ani**.

**Quadro 3 – Regras de Negócio do sistema**

| RN001 - Registro único de memória |
| --- |
| **Descrição**: Cada fragmento de memória pode ser registrado apenas uma vez no diário. |

| RN002 - Progressão fixa entre atos |
| --- |
| **Descrição**: A progressão entre atos ocorre de forma sequencial, seguindo a ordem definida no GDD, sem possibilidade de retorno ou salto de ordem. |

| RN003 - Critério de avanço por conclusão de ato |
| --- |
| **Descrição**: A progressão para o ato seguinte depende da conclusão dos critérios do ato atual. |

| RN004 - Avanço parcial no Ato I |
| --- |
| **Descrição**: No Ato I, o avanço não exige a visualização de todas as memórias, apenas o cumprimento de um limiar mínimo definido. |

| RN005 - Ressignificação de objetos e memórias |
| --- |
| **Descrição**: Um fragmento pode assumir diferentes interpretações ao longo da progressão do jogo, sem alteração de sua identidade original no diário. |

| RN006 - Convergência dos ecos de decisão |
| --- |
| **Descrição**: Nos momentos de eco de decisão no Ato II, diferentes interações do jogador levam ao mesmo impasse narrativo. |
